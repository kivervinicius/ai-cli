# Persistência

O Nexus persiste configuração, projetos, sessões e metadados de execução nos
stores do Core. A recuperação deve ser tratada como estado observável; não
assuma que reiniciar um processo equivale a retomar o mesmo runtime.

Consulte [troubleshooting](../operations/troubleshooting.md) para coletar
diagnósticos sem expor segredos.
