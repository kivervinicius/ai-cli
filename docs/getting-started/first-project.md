# Primeiro projeto e primeira sessão

1. Inicie `nexus web` e abra a URL de bootstrap.
2. Adicione uma pasta de projeto existente pelo seletor de Projects.
3. Use **+ New → AI Session**.
4. Escolha um provider que `nexus providers` detectou.
5. Abra o terminal e envie uma tarefa pequena, verificável e reversível.

Esse é o caminho recomendado para o primeiro resultado. Agents persistentes, Composer, Flow e Mission podem ser explorados depois.

## Se a sessão parar

Distinga a identidade do Agent da geração concreta de Runtime. Um runtime encerrado pode ser recuperável, mas não é automaticamente a mesma sessão do provider. A UI deve mostrar a continuidade real, ou um estado não verificado.
