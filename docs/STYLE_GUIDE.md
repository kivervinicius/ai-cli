# Style guide documental

- Fato verificável vem antes de marketing.
- Uma entidade usa um termo canônico; consulte [GLOSSARY.md](GLOSSARY.md).
- Uma página tem uma finalidade principal.
- README é landing page; manuais detalhados vivem em `docs/`.
- Claims `IMPLEMENTED`, `EXPERIMENTAL`, `PLANNED` e `UNKNOWN` precisam ser explícitos.
- Screenshot deve ser real, sanitizado, identificado por SHA e ter alt text.
- Mermaid explica relações; não substitui evidência visual.
- Use links relativos e valide-os localmente.
- Nunca exponha secrets, cookies, tokens ou paths privados.
- `DEV/` e `.omx/` são contexto interno, não onboarding público.
