Agent options · Codex

Settings are persisted with the Agent definition. Runtime/session continuity is handled separately.
State guarantee
Closing/reopening a Web terminal only detaches and reattaches to the same RuntimeID; the provider process remains alive. If a setting requires restarting the provider, Nexus persists the Agent definition and runtime metadata, creates a checkpoint, restarts the provider and uses provider-native resume only when continuity can be verified. Otherwise it clearly creates a new session with preserved project context.
Planned safe apply
  • Persist Agent settings and current RuntimeID/ProviderSessionID.
  • Determine whether this setting is hot-applicable or requires provider restart.
  • If hot-applicable: apply without touching the terminal/session.
  • If restart required: checkpoint → stop → restart → native resume → verify session.
  • If resume cannot be verified: do not claim continuity; offer Context Handoff/new session.
