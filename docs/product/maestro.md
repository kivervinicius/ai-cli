# Integração com Maestro

O [Orquestrador Maestro](https://github.com/IAPro-Community/Orquestrador-Maestro) é opcional para o caminho Direct.

```text
Nexus  → projects, agents, runtimes, providers, sessions, terminals, workspaces e UX
Maestro → método, skills, risco, gates, processo, review e políticas de verificação
```

Quando a integração não estiver disponível, o Nexus deve reportar `MAESTRO_DEGRADED`, nunca inventar skills, gates ou recomendações.
