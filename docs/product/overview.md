# Visão geral

IAPro Nexus é uma workstation local para operar coding agents. Ele reúne
projetos, sessões, providers, terminais, workspaces e agentes em um Core comum,
com Web, Desktop e CLI como superfícies de operação.

Comece pelo [caminho Direct](direct.md). Composer, Flow e Mission são recursos
progressivos para objetivos que exigem descoberta, dependências, paralelismo,
gates ou execução longa.

Consulte [Superfícies](surfaces.md) para escolher o modo de uso e
[Arquitetura](../architecture/overview.md) para o desenho técnico.
