# Modelo mental

| Termo | Significado |
| --- | --- |
| Project | Raiz de código e contexto operacional. |
| Agent | Identidade persistente de um trabalhador. |
| Runtime generation | Processo concreto que executa um Agent. |
| Session | Interação persistida com um runtime/provider. |
| Provider | CLI ou serviço de IA usado para executar o trabalho. |
| Worktree | Checkout isolado usado para separar alterações. |
| Composer | Refinamento de intenção e compilação de prompt. |
| Flow | Projeção visual/editável de um plano. |
| Mission | Execução coordenada de trabalho aprovado. |
| Maestro | Integração opcional de método, skills, risco e gates. |
