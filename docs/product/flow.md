# Flow

Flow é a superfície visual para inspecionar e ajustar trabalho estruturado. Ele não é um segundo planner nem uma fonte paralela de verdade: representa o plano canônico e devolve mutações válidas ao runtime existente.

Use Flow quando houver dependências, paralelismo, múltiplos agentes, gates, longa duração, recovery ou isolamento. Para uma tarefa curta, Direct ou Composer → Copy/Agent é suficiente.

Posição visual é diferente de dependência de execução. Criar um Flow Draft não inicia Agent, MissionRun ou runtime. No modo Execution, observe estados, attempts, artifacts, blockers e verification reais.
