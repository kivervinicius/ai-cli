# Web, Desktop e CLI

| Superfície | Melhor uso |
| --- | --- |
| **Nexus Web** | Controle, observação e administração no navegador local. |
| **Nexus Desktop** | Shell nativo Wails quando há evidência correspondente para a plataforma. |
| **Nexus CLI** | Scripting, diagnósticos, operação headless e terminal. |

Web e Desktop compartilham o Core quando a capacidade está disponível. Consulte a [matriz](../operations/platform-support.md) antes de tratar uma capacidade nativa como suportada.
