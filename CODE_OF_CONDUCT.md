# Código de Conduta IAPro Nexus

## Compromisso

Para manter a comunidade acolhedora, todos os participantes devem agir com
respeito, boa-fé e foco no produto. Não são aceitáveis assédio, discriminação,
ameaças, exposição de dados pessoais, spam ou comportamento deliberadamente
disruptivo.

## Aplicação

Relatos de comportamento inadequado devem ser enviados em particular aos
maintainers por um canal privado do GitHub. Não publique dados pessoais,
tokens, logs sensíveis ou credenciais em issues e pull requests.

Os maintainers podem editar, ocultar ou rejeitar conteúdo que viole este
código e podem limitar a participação quando necessário. Este documento não
substitui leis ou políticas da plataforma GitHub.

## Escopo

Este código se aplica ao repositório IAPro Nexus, às issues, pull requests,
discussões e demais espaços comunitários mantidos pelo projeto.
