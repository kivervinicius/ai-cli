# Segurança

## Reporte responsável

Não abra uma issue pública para vulnerabilidades não corrigidas. Use um canal
privado de segurança do GitHub, quando habilitado para este repositório, ou
contate os maintainers por mensagem privada no GitHub. Se nenhum canal privado
estiver disponível, informe primeiro que há uma vulnerabilidade sem incluir
detalhes exploráveis ou segredos, para que um canal seguro possa ser combinado.

Inclua, quando for seguro fazê-lo:

- versão ou commit afetado;
- plataforma e ambiente;
- passos mínimos para reproduzir;
- impacto observado;
- uma sugestão de correção, se houver.

Nunca envie tokens, chaves privadas, cookies, dumps de credenciais ou dados de
usuários. Redija esses valores antes de compartilhar qualquer evidência.

## Escopo de segurança

O Nexus é um Community Preview. O repositório possui verificações automatizadas
de vulnerabilidades e testes de autenticação, autorização, redaction e
isolamento, mas essas verificações não constituem certificação externa.

Releases não devem ser consideradas assinadas até que a chave pública de
confiança, assinatura dos artefatos e verificação independente estejam
publicadas e verificadas.
